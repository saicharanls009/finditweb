# FindIt — refreshed website

This is the refreshed version of the supplied FindIt project. The original HTML pages, JavaScript behavior, local-storage demo workflow, and SVG illustrations are retained. The visual refresh updates the color system, buttons, cards, focus states, shadows, hover behavior, and small-screen layout.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload the **contents** of this folder to the root of your GitHub repository (not the enclosing folder).
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait for GitHub Pages to finish deploying.

## Important
This project is a front-end demo. Its reports and claims use browser-local storage; they are not shared between different visitors or devices. Do not enter sensitive personal information.
